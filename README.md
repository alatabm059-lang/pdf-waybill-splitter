# 📄 فاصل ملفات البوليصات

برنامج ويب ذكي لفصل ملفات PDF حسب أرقام البوليصات وإعادة تسميتها تلقائياً.

## المميزات ✨

- ✅ استخراج أرقام البوليصات تلقائياً (3 حروف + 7 أرقام)
- ✅ فصل ملف PDF الواحد إلى عدة ملفات منفصلة
- ✅ إعادة تسمية كل ملف باسم البوليصة
- ✅ ضغط جميع الملفات في ملف ZIP واحد
- ✅ تحميل الملف مباشرة
- ✅ واجهة ويب سهلة وسريعة
- ✅ دعم اللغة العربية كاملاً

## الاستخدام 🚀

### 1. تثبيت المكتبات
```bash
pip install -r requirements.txt
```

### 2. تشغيل البرنامج
```bash
python app.py
```

### 3. فتح الموقع
انتقل إلى `http://localhost:5000` في المتصفح

### 4. استخدام البرنامج
1. اسحب ملف PDF أو انقر لاختياره
2. اضغط "معالجة الملف"
3. سيتم تنزيل ملف ZIP يحتوي على جميع الملفات المنفصلة

## الملفات 📁

- `app.py` - البرنامج الرئيسي (Flask)
- `templates/index.html` - صفحة الويب
- `requirements.txt` - المكتبات المطلوبة

## المتطلبات 🔧

- Python 3.7+
- Flask
- PyPDF2

## نموذج البيانات 📋

صيغة رقم البوليصة المتوقعة:
- 3 حروف إنجليزية كبيرة + 7 أرقام
- مثال: `ABC1234567`

## ملاحظات ℹ️

- يعمل بأفضل شكل مع ملفات PDF واضحة وسهلة القراءة
- يتم البحث عن رقم البوليصة في الصفحة الأولى من كل قسم
- الملفات المفصولة تُحفظ مؤقتاً ثم تُحذف بعد الضغط
